# ilibx

iLib-compatible native i18n library, written in Rust.

ilibx gives native apps (Rust, C/C++, LVGL, and later others) the same
results as iLib / flutter_ilib for the same locale and input. It has no
dependency on ICU (ICU4C, ICU4X or any ICU4X-project crate).

On a device there is exactly one copy of the library and one copy of the data:

```
/usr/lib/libilibx.so.1          shared library, C ABI (header: ilibx.h)
/usr/share/ilibx/locale.bin     locale data, memory-mapped and shared by all apps
```

> Status: skeleton only. No functionality yet.

## Layout

| Path | What | Output |
|---|---|---|
| `crates/ilibx-core` | All i18n logic (ported from flutter_ilib). `no_std` + `alloc`, no OS access | linked into `libilibx.so` |
| `crates/ilibx-ffi` | C ABI entry point; opens data, reads system time zone | `libilibx.so` (cdylib) |
| `crates/ilibx-rust` | Thin Rust API for Rust apps; calls `libilibx.so`. Holds no logic and does **not** depend on the core | compiled into each Rust app |
| `include/` | C header `ilibx.h`, generated by cbindgen | |
| `tools/datagen` | Build-time converter: flutter_ilib `assets/locale` → `locale.bin` | build machine only |
| `tools/ilibx-dump` | Prints the contents of a `locale.bin` | build machine only |
| `data/` | Locale data input (flutter_ilib assembled data) | |
| `tests/` | Compatibility tests against flutter_ilib expected values | |
| `scripts/` | `check-no-icu.sh` | |

## Build

```sh
cargo build
cargo test
./scripts/check-no-icu.sh        # no ICU-related crates in the dependency graph
cargo deny check                 # licenses + banned crates (deny.toml)
```

## C ABI conventions

- Functions are named `ilibx_*`, types `Ilibx*`. Strings are UTF-8.
- Results are written to a caller-supplied buffer. The return value is the
  full length needed (without NUL), or a negative error code.
- Objects use `*_new` / use / `*_free`. No callbacks.
- Existing functions never change within a soname; changing or removing one
  bumps `libilibx.so.1` → `.so.2`.
